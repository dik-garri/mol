# Инструкция для агента-обработчика

Ты конвертируешь файлы из `archive/tobeprocessed /` (обрати внимание: пробел в конце имени папки) в markdown с YAML-frontmatter и кладёшь в `archive/<slug>.md`.

## Что тебе дадут
- Список из **2 файлов** (тема + slug + имя файла-источника)
- Никаких других файлов трогать не нужно

## Процесс для КАЖДОГО файла

### 1. Конвертация в markdown
В зависимости от расширения:
- **`.docx`** → `pandoc "archive/tobeprocessed /<имя>.docx" -t markdown --wrap=none -o /tmp/conv-<slug>.md`
- **`.pdf`** → `pdftotext -layout "archive/tobeprocessed /<имя>.pdf" /tmp/conv-<slug>.md` (выход – plain text, придётся вручную добавить markdown-структуру)
- **`.pptx`** → `pandoc "archive/tobeprocessed /<имя>.pptx" -t markdown --wrap=none -o /tmp/conv-<slug>.md` (слайды разделены `---`)
- **`.pages`** / **`.odt`** → попробовать pandoc, если не получится – пометить ⚠️

### 2. Очистка вывода
Pandoc-артефакты, которые надо убрать или починить:
- `**текст**` в заголовках `# **...**` → `# ...` (убрать **)
- `[текст]{.underline}` → `**текст**` (превратить underline в bold)
- `[текст]{.mark}` → `**текст**`
- `\*` → `*` (escape)
- Удалить пустые маркеры списков (`- ` без текста)
- Объединить ломаные строки внутри одного абзаца

### 3. Определить метаданные
- **title**: из имени файла (без расширения, без trailing-пробелов; для библейских отрывков – нормализовать вид «1 Фессалоникийцам 1:1–5»)
- **subtitle**: первое осмысленное предложение из текста, если есть
- **date**: **mtime файла-источника в формате YYYY-MM**. Получить:
  ```bash
  python3 -c "import time; from pathlib import Path; print(time.strftime('%Y-%m', time.localtime(Path('archive/tobeprocessed /<имя>.docx').stat().st_mtime)))"
  ```
  Это отражает реальный месяц подготовки материала. Если что-то экзотическое и mtime недоступен – fallback `2018-01`
- **tags**: 3–6 шт. Что включать:
  - Библейская книга/глава (например: `1 Фес. 1`, `Мф. 5`)
  - Тематические ключи (например: `молитва`, `смирение`, `вера`)
  - Жанр: `проповедь` если это конспект, `разбор` если разбор отрывка, `тема` для тематических

### 4. Записать итоговый файл
Путь: `archive/<slug>.md`. Шаблон:

```markdown
---
title: "<Тема>"
subtitle: "<подзаголовок или удалить эту строку>"
date: "2018-01"
tags: ["<тег1>", "<тег2>", "<тег3>"]
---

<очищенный markdown-контент>
```

## Что НЕ делать
- НЕ переписывать содержимое, не «улучшать» текст, не добавлять/убирать смысл. Только конверт + чистка артефактов
- НЕ обрабатывать другие файлы кроме тех, что тебе дали
- НЕ редактировать ARCHIVE_TRACKER.md – это сделает координатор после твоего отчёта
- НЕ запускать build.py – это тоже сделает координатор

## Что вернуть в итоге

Краткий отчёт для каждого файла:
```
File 1: <имя>
  → archive/<slug>.md (XXX строк)
  Tags: [...]
  Issues: <если были, иначе "—">

File 2: ...
```

Если файл повреждён, пустой или нерелевантен (например, чьи-то заметки) – пометить как ⚠️ или ❌ и объяснить.
